Assistance

Un problème, une question, une idée ? Ouvrez un ticket sur GitHub (n'y mettez jamais de mot de passe ni de clé privée).

Questions fréquentes

Où sont mes serveurs et mes clés ? Sur votre appareil seulement. Les clés et mots de passe sont dans le Trousseau iOS.

Que faire si TacTerm refuse de se connecter parce que l'empreinte a changé ? Le serveur a peut-être été réinstallé. Vérifiez l'empreinte sur le serveur (ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub) ; si elle est légitime, oubliez l'hôte dans Réglages et reconnectez-vous. Sinon, ne vous connectez pas.

Comment restaurer mon achat ? Réglages › Restaurer mes achats, avec le même identifiant Apple.

Mes serveurs sont derrière Tailscale. Installez l'app Tailscale officielle, connectez-la, puis utilisez l'adresse Tailscale du serveur.

Support

A problem, a question, an idea? Open an issue on GitHub (never post a password or private key).

FAQ

Where are my servers and keys? On your device only. Keys and passwords are in the iOS Keychain.

TacTerm refuses to connect because the fingerprint changed. The server may have been reinstalled. Check the fingerprint on the server (ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub); if it is legitimate, forget the host in Settings and reconnect. Otherwise, do not connect.

How do I restore my purchase? Settings › Restore purchases, with the same Apple ID.

My servers are behind Tailscale. Install the official Tailscale app, sign in, then use the server's Tailscale address.
